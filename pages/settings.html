Account security and access

This application currently uses browser LocalStorage and a demo login. The signed-in Owner session gates settings in this browser only; it is not server-enforced authentication and can be changed by someone with browser storage access. Email verification, secure password changes, recovery, and trusted multi-user roles are not available until a backend authentication service is configured.
